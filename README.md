# Content Agent Orchestrator

  Proyecto para coordinar agentes que participan en la creación de contenido.

  ## Requisitos

  - uv.
  - Python 3.12 o superior.

  ## Preparación

  Desde la carpeta del proyecto, ejecutar:

  ```powershell
  uv sync
  ```

  Este comando crea el entorno virtual `.venv` e instala las dependencias.
