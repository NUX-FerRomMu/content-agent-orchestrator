# Instrucciones del proyecto

  - Administrar el entorno y las dependencias con uv.
  - Usar el entorno virtual .venv.
  - Consultar antes de agregar dependencias.
  - Ejecutar las pruebas relevantes después de modificar código.
  - Generar pruebas automatizadas después de modificar el código que validen la lógica agregada.
  - No leer ni mostrar archivos .env con secretos.
